个人记账 v1.2 使用手册

桌面独立窗口、无需浏览器；支持 Excel / CSV 旧账本导入、按秒或按日显示时间、导入数据「确认后才冻结」。

桌面版本地数据Excel/CSV 导入延迟冻结

1安装与启动

1.1 安装

  1. 双击 记账v1.2-安装包.exe。
  2. 选择安装位置（默认 %LOCALAPPDATA%\Programs\记账v1.2，不需要管理员权限）。
  3. 按需勾选「创建桌面快捷方式」「创建开始菜单快捷方式」「安装后立即启动」，点「安装」。
  4. 安装完成后，桌面 / 开始菜单出现「个人记账 v1.2」，双击即可使用。
Windows 可能提示「未知发布者」 安装包未做数字签名，首次运行会出现 SmartScreen 蓝屏提示：点「更多信息」→「仍要运行」即可，属正常现象。

1.2 三种启动方式

方式说明适用场景
桌面 / 开始菜单「个人记账 v1.2」打开独立窗口（推荐）日常记账
安装目录下 ledger-desktop.exe同上，效果一致便携使用
ledger.exe以浏览器方式打开（默认 http://127.0.0.1:8770）排查问题 / 多屏对照
单实例 重复双击不会开出第二个窗口，而是把已开的窗口切到前台。v1.1 与 v1.2 可以同时运行，互不干扰。

1.3 卸载

「设置 → 应用 → 个人记账 v1.2 → 卸载」，或开始菜单「个人记账 v1.2 → 卸载」。

卸载默认保留账本数据 账本存在数据目录（见第 18 章），卸载只删程序。要连数据一起删，需在卸载界面勾选「同时删除用户数据」。

2首次使用

第一次启动会自动完成三件事：初始化账本、生成访问令牌、创建默认账户。

2.1 只有一个「总账户」

v1.2 起账户模型收敛为单账户：总账户。适合不区分银行卡/支付宝/微信的用户，导入历史账本时所有记录都归到它名下。

  • 如果你确实要区分多张卡，可在「设置 → 账户」新增账户，之后记账时可选。
  • 内部转账需要至少两个账户；只有一个账户时该选项卡置灰并提示（避免"自己转给自己"）。

2.2 桌面版自动登录

桌面版首次启动会自动注入本机令牌，打开即进入首页，无需手动粘贴 64 位令牌。浏览器方式（ledger.exe）首次需要登录，令牌打印在启动窗口或日志里。

3界面导览

首页 / 仪表盘本月收支、余额走势、分类排行、高额消费、最近交易
明细全部交易，支持筛选、搜索、编辑、删除、回收站
导入Excel / CSV 账本导入、微信/支付宝 CSV、截图识别
报表按月/年、按分类的多维统计

侧边栏底部会显示当前版本号（如「个人记账 v1.2.0」），可用它确认自己在用哪个版本。

4快速记账

首页或明细页点「记一笔」，默认进入快速模式：只填金额 + 分类即可保存，适合日常高频记录。

  1. 选择支出 / 收入 / 转账。
  2. 输入金额（支持 12.5、￥12.50，自动保留两位小数）。
  3. 选分类（常用分类可拖到前面）。
  4. 可选：时间、账户、标签、备注。
  5. 点「保存」。

5完整记账

快速模式里点「完整表单」，可填写全部字段：时间（受「时间显示」精度影响）、账户、分类、标签、商户、备注、物品明细。

5.1 物品明细

一笔消费包含多件物品时，可逐行填写：物品名称、原价、实付、折扣（自动计算）、折扣缘由，并用 ↑↓ 调整顺序。

v1.2 修复 明细表曾出现右侧列超出弹窗的问题（窄窗口下尤为明显）。现已改为：表格宽度自适应弹窗，空间不足时表格内部横向滚动，不再撑破弹窗。

5.2 金额与方向

  • 支出填正数，系统按类型记账；不要用负数表示支出。
  • 收入请在收入类型下录入，分类建议用「收入」类。
  • 转账会同时生成转出与转入两条分录，两边金额一致。

6转账与调整分录

6.1 内部转账

在同一账本内、两个不同账户之间转移资金。选择转出账户、转入账户、金额、时间即可。

只有一个账户时不可用 转出与转入不能是同一账户；请先在「设置 → 账户」新增第二个账户。

6.2 调整分录

当一笔历史记录已冻结（只读），而你发现金额错了、分类错了，不需要解冻，用「调整」补一笔差额即可，原始记录保持不变，便于追溯。

  • 在明细里找到该笔 → 点「调整」→ 填写调整金额与原因。
  • 调整分录会以独立记录出现在同一天，报表按合计口径自动平衡。

7冻结区规则

超过「冻结天数」（默认 30 天，可在设置中改 10–365）的记录会进入冻结区，只读，防止误改历史。

状态界面表现能否编辑
正常（近期）无标记可编辑、可删除
已冻结行首橙色竖条 + 「冻结」徽标不可编辑，需用「调整」
待确认冻结（导入的历史数据）蓝灰虚线「待确认冻结」标签，余额列显示 —可编辑、可删除，确认后才锁定
为什么有「待确认冻结」 导入几年前的老账本时，你多半需要先核对、改错。v1.2 会把这些记录先留在可编辑状态，等你点「确认冻结」后才真正锁定。

8导入旧账本（Excel / CSV）

入口：左侧「导入」→ 默认标签页「Excel / CSV 账本导入」。

8.1 支持与不支持

格式支持说明
.xlsx / .xlsm✅推荐；一个文件可有多张工作表
.csv✅UTF-8 / UTF-8 BOM / GBK 自动识别
.txt（表格型）✅按 CSV 处理
.xls（Excel 97-2003）❌请先用 Excel / WPS「另存为 .xlsx」

8.2 五步流程

  1. 选文件：可一次拖入多个文件；.xls 会在此步被拦下并提示另存。
  2. 选表单：同一文件内的多张工作表会全部列出，自己勾选要导入的（可多选）。汇总表/透视表会被标注「疑似汇总表，建议不导入」。
  3. 列映射：为每张表指定「哪一列是日期、金额、分类、账户、标签、备注、方向」。系统会自动识别，识别不准时手动改即可；可点「应用到其他表」批量套用。
  4. 预览：显示前 200 行、错误行原因、将自动新建的分类/标签、同日时间分布样例，并选择冻结策略（见第 10 章）。
  5. 提交：显示成功导入条数、重复跳过、失败条数；可跳转查看新记录。

8.3 多文件 / 多表单

  • 一次导入多个文件：各文件的表单一并出现在第 2 步，按需勾选。
  • 同一文件多张表：可只导「明细」不导「统计」，避免重复计账。
  • 不同文件可设置不同的列映射。

8.4 分类与标签自动创建

源表里的分类/标签在软件中不存在时，会自动创建（挂在一级分类下），无需手工预建。

近义分类不会自动合并 例如「其他」与「其它」会作为两个独立分类保留，保证与原始账本一致；如需合并请到「设置 → 分类」手动处理。

9列映射与校验

9.1 必填与可选

字段是否必填说明
日期必填支持 2024-01-05、2024/1/5、2024年1月5日、Excel 日期序列号
金额必填支持 ¥1,234.56、(123.45) 负数写法
分类可选缺失时可用默认分类
账户可选缺失统一归「总账户」
标签 / 备注 / 商户可选备注常被用作「消费项目」
收支方向可选无此列时按「表默认方向」判定，或分类为「收入」视为收入

9.2 只有日期没有时间怎么办

旧账本通常只记到日。导入时系统会把同一天的记录按原始行顺序，平均分布到这一天 24 小时内，保证时间不重复、顺序不乱；单条记录默认落在 12:00:00。

这些分布出来的时间是"占位" 它们只用于排序与展示，界面会给这类记录加小圆点提示「时分秒由系统按当日分布」，不会被当成你精确录入的时间。

9.3 失败与重试

预览页会用红/黄/橙标记问题行：红色=无法解析（缺日期/金额非法）、黄色=疑似重复、橙色=落进冻结区。修正映射后可直接回上一步重试，已选文件与映射不会丢。

10导入后确认冻结（v1.2 新规则）

导入的历史数据默认不会立刻锁定，而是标记为「待确认冻结」，方便你核对、改错。

10.1 导入时选择策略

选项效果适合
先让我核对，确认后再冻结（默认）超过冻结天数的记录保持可编辑首次导入老账本
导入后立即冻结等同旧版行为，历史记录直接只读数据源可信、不需要核对

10.2 三个确认入口

  1. 导入结果页：显示「N 笔历史数据待确认冻结」，点「全部确认冻结」一次锁定整批。
  2. 明细列表：工具栏「待确认冻结 (N)」可筛选出全部待确认记录，核对后批量确认。
  3. 详情抽屉：单笔点「确认此笔」，适合逐条校对。

10.3 确认前后数字不变

确认只是把记录从"可编辑"切到"只读"，总余额、收支统计、报表口径都不会变化。确认后该行标签消失、余额列恢复显示，再编辑会提示使用「调整分录」。

建议节奏 先按分类/月份抽查几笔 → 修正明显错误（金额、分类） → 再整批确认。确认后仍可改，只是要走调整分录。

11微信 / 支付宝账单 CSV

「导入」→「CSV 导入」标签页，专用于微信支付、支付宝导出的官方账单文件，字段已内置适配，只需选择文件与账户即可，无需手工映射。

  • 微信账单通常在「我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单」获取。
  • 支付宝在「我的 → 账单 → 右上角 → 开具交易流水证明」获取。
  • 这两种账单带交易号，重复导入会自动识别并跳过。

12截图识别（OCR）

「导入」→「截图识别」，上传账单截图，系统尝试识别金额、商户、时间并生成待确认草稿。

需要 OCR 服务 OCR 依赖可选的 Python 识别服务；未启动时该功能不可用，不影响其他功能。识别结果务必人工核对后再保存。

13账户管理

13.1 合并为总账户

「设置 → 账户」顶部可把多个账户合并到「总账户」：勾选源账户 → 输入 MERGE 确认 → 系统先自动备份，再合并并全量重算。

合并不可逆 合并后无法再按原账户查看历史余额（备份里仍有）。确认页会展示每个账户合并前的余额，便于事后查证。

13.2 新增账户

「设置 → 账户 → 新增」，填写名称、类型、初始余额。若需要内部转账，至少要有两个账户。

13.3 初始余额

初始余额代表"开始记账那一刻"该账户里已有的钱，不参与收支统计，只影响余额曲线起点。

16统计与报表

  • 首页仪表盘：本月收入/支出/结余、余额走势、分类排行、高额消费、最近交易。
  • 报表页：按月份/年份汇总，可按分类下钻；时间范围支持预设与自定义。
  • 统计口径按「本地日期」聚合，不受时间显示精度影响：切成「年月日」也不会让本月合计变化。
  • 冻结区与待确认冻结的记录都计入统计。

17备份与恢复

  1. 「设置 → 备份 → 立即备份」生成一个备份包（默认在数据目录 backups/ 下）。
  2. 可下载到本地或网盘长期保存。
  3. 恢复：选择备份文件 → 确认 → 系统会先备份当前数据，再覆盖恢复。
重要操作前会自动备份 账户合并、库结构升级（如 v1.1 → v1.2）都会先自动备份，备份文件保留在 backups/ 下，可随时回退。

18数据存放与迁移

18.1 数据目录

内容路径
账本数据库%LOCALAPPDATA%\个人记账\data\ledger.db
备份…\data\backups\
日志…\data\logs\
截图 / OCR 结果…\data\screenshots\、…\data\ocr-results\
界面缓存…\data\web-assets\、…\data\webview2\（可删，不影响账本）

18.2 换电脑 / 迁移

  1. 在旧电脑「设置 → 备份」做一次备份，或直接复制 data\ledger.db。
  2. 新电脑安装 v1.2，先启动一次并完全退出。
  3. 把备份恢复（推荐），或用 ledger.db 覆盖新电脑同名文件。
覆盖前先关闭程序 数据库运行时被占用，直接覆盖可能失败或损坏。请确认任务栏/任务管理器里没有 ledger-desktop.exe。

18.3 从 v1.1 升级

v1.2 直接复用同一数据目录，安装后打开即可看到原有账本；首次启动会自动升级数据库结构（先备份），并把多账户合并为「总账户」。

19常见问题

Q1：打开后界面还是旧样子，没有账本导入？

先确认窗口标题是「个人记账 v1.2」、侧边栏底部版本是 1.2.0。若是旧版本，说明启动的是旧程序；如果是 1.2 但界面没变，清理界面缓存后重开：

  • 关闭程序，删除 %LOCALAPPDATA%\个人记账\data\webview2 目录，再启动；
  • 或用命令行加参数启动一次：ledger-desktop.exe --reset-ui-cache（只清界面缓存，不动账本）。

Q2：导入后金额合计和原表对不上？

  • 检查是否误勾了「统计」这类汇总表（会造成重复计账）；
  • 检查金额列是否选错（例如选成了「余额」而不是「发生额」）；
  • 预览页的错误行数与失败条数会给出原因。

Q3：导入的历史记录改不了？

说明已经确认冻结（行首橙色竖条）。用「调整」补一笔差额，或说明你导入时选了「立即冻结」——下一批导入改选「先核对再冻结」。

Q4：内部转账是灰的？

只有「总账户」一个账户时不可用。到「设置 → 账户」新增第二个账户即可。

Q5：卸载后我的账本还在吗？

在。卸载默认保留数据目录；重新安装同一版本即可继续使用。要彻底删除需在卸载界面勾选「同时删除用户数据」。

Q6：提示缺少 WebView2 运行时？

Windows 10 1803+ 与 Windows 11 通常自带。若确实缺失，按弹窗提示到微软官网下载「WebView2 Runtime」安装后重试；临时应急可运行同目录的 ledger.exe 用浏览器打开。

Q7：能不能把数据放网盘同步？

不建议直接同步 ledger.db（写入过程中同步可能损坏）。推荐定期「备份」后同步备份文件。

Q8：导入的「其他」和「其它」为什么是两个分类？

为了与原账本严格一致，系统不会自动合并近义分类。可在「设置 → 分类」手动把其中一个的记录改到另一个，再停用多余分类。
